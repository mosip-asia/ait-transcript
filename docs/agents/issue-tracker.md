# Issue tracker: local Markdown, outside this repo

Thas tracks work on this repo as Markdown files in the workspace that holds this clone (`D:\MOSIP\.scratch\<feature>\`), not in this repo and not in GitHub Issues. The workspace's own `docs/agents/issue-tracker.md` has the file conventions.

GitHub Issues on `mosip-asia/ait-transcript` belong to other people. Read them when one is referenced, but never create, label, comment on or close one.

- **Publish to the issue tracker**: a new file under `.scratch/<feature>/`.
- **Fetch the relevant ticket**: read the file at the path given.
- **Triage state**: a `Status:` line near the top of the file, one of `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.
