# Inji Wallet for iOS

```sh
BUNDLE_ID=com.yourorg.aitwallet TEAM_ID=ABCDE12345 ./wallet/apply.sh ios my-wallet
cd my-wallet
export PATH=/opt/homebrew/opt/node@20/bin:$PATH LANG=en_US.UTF-8   # Node 20, not 26
npm install && (cd ios && pod install)
open ios/Inji.xcworkspace          # pick your iPhone, Run (or Archive for TestFlight)
```

`BUNDLE_ID` and `TEAM_ID` are required: the patch carries the placeholders `com.example.aitwallet` and `XXXXXXXXXX`, which the script replaces. Register that bundle id on your Apple Developer team, and create an App Store Connect record before a TestFlight upload. Use a **physical iPhone**: v0.22.1 does not run in the simulator. Connection details, the flow and the full build notes: [wiki/guides/wallet-developer-urls.md](../../wiki/guides/wallet-developer-urls.md).

## What `ait-ios.patch` changes (8 files)

| File | Change |
|---|---|
| `ios/Inji.xcodeproj/project.pbxproj` | bundle id and team (placeholders), automatic signing, `Apple Development` identity, empty entitlements, iOS 15 deployment target, the `SceneDelegate` sources |
| `ios/Inji/InjiAit.entitlements` | empty: drops iCloud, Push and Sign in with Apple |
| `ios/Inji/Info.plist` | `UIApplicationSceneManifest` (iOS 27 kills apps without it) |
| `ios/Inji/SceneDelegate.h`, `.mm` | adopts the scene lifecycle, hands the React Native window to the scene, forwards URLs |
| `ios/Podfile` | iOS 15 minimum, explicit Swift/Clang modules off (Xcode 16+) |
| `ios/Podfile.lock` | regenerated by `pod install` for the above |
| `patches/expo-localization+15.0.3.patch` | `@unknown default` in a calendar switch (new Swift enum cases) |

The shared `.env` change is in [../common](../common/ait-common.patch). Regenerating and verifying the patches: [../README.md](../README.md#maintaining-the-patches).
