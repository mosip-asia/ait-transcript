# Inji Wallet for the AIT transcript platform

The changes that make **Inji Wallet v0.22.1** talk to the AIT transcript platform on GCP, as one patch on top of the upstream release. This repo does not carry Inji Wallet itself: the script clones [inji/inji-wallet](https://github.com/inji/inji-wallet) at `v0.22.1` (MIT, MOSIP) and applies the patch.

```sh
# your own Apple bundle id and Developer Team ID (both required to sign and run on a device)
BUNDLE_ID=com.yourorg.aitwallet TEAM_ID=ABCDE12345 ./wallet/apply.sh my-wallet
cd my-wallet
export PATH=/opt/homebrew/opt/node@20/bin:$PATH LANG=en_US.UTF-8   # Node 20, not 26
npm install && (cd ios && pod install)
open ios/Inji.xcworkspace          # pick your iPhone, Run (or Archive for TestFlight)
```

`BUNDLE_ID` and `TEAM_ID` are required: the patch carries the placeholders `com.example.aitwallet` and `XXXXXXXXXX`, which the script replaces. Register that bundle id on your Apple Developer team (and create an App Store Connect record before a TestFlight upload). Use a **physical iPhone**: v0.22.1 does not run in the simulator. iOS only; Android is untried. Connection details, the flow, and the full build notes: [wiki/guides/wallet-developer-urls.md](../wiki/guides/wallet-developer-urls.md).

## What the patch changes (9 files)

| File | Change |
|---|---|
| `.env` | `MIMOTO_HOST`, `ESIGNET_HOST`, `OBSRV_HOST` -> `https://api.transcript-demo.ait-vc.dpi.ait.ac.th` (also stops telemetry going to MOSIP) |
| `ios/Inji.xcodeproj/project.pbxproj` | bundle id and team (placeholders), automatic signing, `Apple Development` identity, empty entitlements, iOS 15 deployment target, the `SceneDelegate` sources |
| `ios/Inji/InjiAit.entitlements` | empty: drops iCloud, Push and Sign in with Apple |
| `ios/Inji/Info.plist` | `UIApplicationSceneManifest` (iOS 27 kills apps without it) |
| `ios/Inji/SceneDelegate.h`, `.mm` | adopts the scene lifecycle, hands the React Native window to the scene, forwards URLs |
| `ios/Podfile` | iOS 15 minimum, explicit Swift/Clang modules off (Xcode 16+) |
| `ios/Podfile.lock` | regenerated by `pod install` for the above |
| `patches/expo-localization+15.0.3.patch` | `@unknown default` in a calendar switch (new Swift enum cases) |

## Maintaining it

The patch is a staged diff against the upstream tag with the signing identity replaced by the placeholders above. After changing the wallet, regenerate it from a checkout (put your identity back to the placeholders first, and leave out `.talismanrc` and your build number):

```sh
git add -A && git diff --cached --binary v0.22.1 > <this repo>/wallet/ait-wallet-v0.22.1.patch
```

Verify by running `apply.sh` into a new directory with your own `BUNDLE_ID` / `TEAM_ID` and checking that the result builds and matches your checkout apart from those values. Moving to a newer Inji Wallet means rebasing the changes and renaming the patch, since several of them (deployment target, scene lifecycle, Podfile) are workarounds for Xcode 27 / iOS 27 that a newer upstream may already contain.
